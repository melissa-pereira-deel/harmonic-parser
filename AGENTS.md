# Project memory

For work on the live playing experience, read [the project memory](docs/project-memory.md) before making design or implementation decisions. Follow its links for the current brief, prior decisions, and evidence.

At the end of a session that changes the project direction, append a dated entry to the memory and update its current snapshot. Separate what the user confirmed, what the team observed, what is proposed, and what remains open. When a decision changes, link the new entry to the earlier one and keep the original rationale. Record durable context and evidence rather than copying transcripts.
